## 한국어

CSS를 공부하면서 만든 버튼 컬렉션입니다.

다양한 CSS 기능을 연습하면서 여러 가지 스타일의 버튼을 만들어봤습니다.

현재 20개 이상의 버튼 스타일이 포함되어 있으며, 계속 추가할 예정입니다.

### 특징

- 다양한 버튼 디자인
- CSS Gradient
- `::before` 가상 요소
- Hover / Active 효과
- Transition & Transform
- Glassmorphism
- Responsive Layout
- 순수 HTML + CSS
- JavaScript 없이 작동
- 자유롭게 사용 가능

### 사용 방법

`index.html`을 열거나 원하는 버튼의 HTML/CSS를 프로젝트에 복사해서 사용할 수 있습니다.

예시: `<button class="btn btn-neon">Neon</button>`

해당 버튼에 필요한 CSS도 함께 추가하면 됩니다. (예: btn, btn-neon 등의 클래스)

## English

A collection of modern, colorful, and experimental CSS buttons made while learning HTML and CSS.

This project started as a small CSS practice project and gradually grew into a collection of 20+ button styles.

More styles may be added over time.

### Features

- Various button designs
- CSS gradients
- `::before` pseudo-elements
- Hover / Active effects
- Transitions & transforms
- Glassmorphism
- Responsive layouts
- Pure HTML + CSS
- No JavaScript required
- Free to use

### Included Styles

- Neon
- Glass
- Soft
- Mint
- Gold

- Cyan
- Pixel
- Spark
- Coral
- Silver
- Forest
- Midnight
- And more

> More button styles may be added in the future.

### Usage

Open `index.html`, or copy the HTML and CSS of the button you want to use into your own project.

For example: `<button class="btn btn-neon">Neon</button>`

Then include the corresponding CSS for the button. (e.g., classes such as btn, btn-neon, etc.)
